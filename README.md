# Meu Treino 🏋️‍♂️

Aplicativo web mobile-first para registro e acompanhamento de treinos de musculação e bioimpedância, focado em agilidade no celular e custo zero.

## 📱 Acesso Rápido
Acesse online: [https://bilard-dev.github.io/meu-treino/](https://bilard-dev.github.io/meu-treino/)

## ✨ Principais Funcionalidades
- **Login sem Complicação (Estilo Netflix):** Escolha de perfil e PIN numérico de 4 dígitos.
- **Inteligência por Academia:** 
  - Máquinas e polias: lembra a carga específica da academia onde você está treinando.
  - Pesos livres (halteres/barras): acompanha a progressão geral.
- **Modelos de Treino (Fichas):** Crie e edite suas fichas (Treino A, B, C...).
- **Treino do Dia Flexível:** Abra uma ficha e adicione ou remova exercícios na hora sem alterar o modelo base.
- **Registro Rápido de Séries:** Peso (kg), repetições e descanso com interface de toque rápido.
- **Medidas Corporais Duplas:**
  - Pesagem diária rápida.
  - Exame completo de bioimpedância (% de gordura, massa muscular, água, visceral, metabolismo basal).
- **Evolução Visual:** Histórico cronológico em lista e gráficos de progressão de carga.

## 🚀 Como "Instalar" no Celular como Aplicativo (PWA)
1. Abra o link do site no navegador do celular (Chrome ou Safari).
2. Toque no botão de compartilhar/opções (três pontinhos no Android ou botão de compartilhar no iPhone).
3. Selecione **"Adicionar à tela de início"** ou **"Instalar aplicativo"**.
4. O ícone do **Meu Treino** aparecerá na tela do seu celular como um app nativo!

## 🛠️ Tecnologias
- **Frontend:** React + Vite + Tailwind CSS + Lucide Icons
- **Backend e Banco de Dados:** Supabase (PostgreSQL)
- **Hospedagem:** GitHub Pages
